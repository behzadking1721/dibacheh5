## 📖 درباره پروژه

**خلاصه کده** یک پلتفرم وب پیشرو (Progressive Web App) جهت دسترسی به چکیده و نکات طلایی پرفروش‌ترین کتاب‌های موفقیت، رشد فردی، روانشناسی، مدیریت، کسب‌وکار، بیوگرافی و رمان‌های شاخص جهان به زبان فارسی است. این سامانه با تمرکز ویژه بر **خوانایی بالا، سرعت بی‌نظیر، عملکرد آفلاین و بدون خستگی چشم** توسعه یافته است.

## ✨ امکانات و قابلیت‌های پیاده‌سازی‌شده

### 🎯 ۱. دسته‌بندی‌های اختصاصی و موضوعی صفحه اول
- **بخش کتاب‌های پیشنهادی سردبیر:** گزینش روزانه با ارزش محتوایی فوق‌العاده.
- **عناوین ترند و پربازدید:** کتاب‌های داغ و مورد بحث در بین کتاب‌خوان‌ها.
- **تازه‌ترین خلاصه‌ها:** اضافه شدن پیوسته چکیده کتاب‌های جدید.
- **محبوب‌ترین و مشهورترین آثار:** کلاسیک‌ها و شاهکارهای پرامتیاز جهانی.
- **قفسه «باید بخوانم» (نوبت مطالعه):** دسترسی سریع به کتاب‌های رزرو شده توسط کاربر مستقیماً در صفحه اول.

### 🔖 ۲. مدیریت نوبت مطالعه (Reading List / Want to Read)
- دکمه نشانه «افزودن به نوبت مطالعه» روی کارت کتاب‌ها، پنجره جزئیات و انتهای متن خواندن.
- تب اختصاصی **«🎯 باید بخوانم»** در منوی ناوبری همراه با شمارنده زنده.
- تفکیک و نمایش کتاب‌های نوبت مطالعه در پروفایل شخصی با امکان آغاز آنی مطالعه یا حذف از نوبت.

### 🔍 ۳. پیشنهاد کتاب‌های مشابه و مکمل (Smart Recommendations)
- سیستم پیشنهاددهی هوشمند براساس دسته‌بندی و موضوع کتاب در پایین پنجره معرفی.
- نمایش کتاب‌های مرتبط در انتهای ریدر برای حفظ زنجیره مطالعه و اشتیاق خواننده.

### 💬 ۴. سیستم نقد، بررسی و امتیازدهی کاربران (Community Reviews)
- امکان ارسال نظر به همراه امتیاز ستاره‌ای (۱ تا ۵ ستاره).
- محاسبه خودکار میانگین امتیاز کتاب با هر بازخورد جدید.
- قابلیت لایک کردن نظرات مفید دیگر خوانندگان.

### ⏰ ۵. سیستم یادآور روزانه مطالعه (Daily Reminder & Push/Toast)
- **ارسال یادآور هوشمند:** دعوت به مطالعه در ساعت معین از شبانه‌روز متناسب با برنامه کاربر.
- **شناسایی کتاب فعال:** یادآوری کتاب در حال مطالعه با نمایش درصد پیشرفت برای ادامه سریع.
- **اعلان دوگانه (Push Notification & In-App Toast):** پشتیبانی از نوتیفیکیشن مرورگر در پس‌زمینه به همراه توست شناور تعاملی درون برنامه.
- **صدای زنگ ملایم (Web Audio Chime):** ملودی دلنشین و آرامش‌بخش بدون نیاز به فایل صوتی حجیم.
- **قابلیت Snooze (یادآوری مجدد ۱۰ دقیقه بعد):** برای مواقعی که کاربر در حال حاضر فرصت مطالعه ندارد.
- **دکمه تست آنی و تنظیم زمان دلخواه:** امکان تست فوری خروجی اعلان و انتخاب ساعت مشخص (صبح، ظهر، عصر، شب یا ساعت دلخواه).

### 📖 ۶. محیط مطالعه حرفه‌ای و متمرکز (In-App Reader)
- تنظیم اندازه قلم، فونت وزیرمتن و فاصله بین خطوط برای راحتی چشم.
- حالت مطالعه شب، روز و سپیا (Sepia).
- **سیستم هایلایت چندرنگ:** امکان نشانه‌گذاری بخش‌های کلیدی با رنگ‌های مختلف.
- **یادداشت‌برداری حین مطالعه:** ثبت ایده‌ها و افکار شخصی برای هر جمله.
- محاسبه و نمایش زنده درصد پیشرفت مطالعه و ذخیره موقعیت آخرین صفحه خوانده‌شده.

### 📴 ۶. پشتیبانی کامل از مطالعه آفلاین و PWA
- امکان دانلود متون خلاصه‌ها و ذخیره محلی با یک کلیک.
- نشانگر هوشمند وضعیت اتصال اینترنت (آنلاین/آفلاین).
- دکمه نصب اپلیکیشن روی صفحه اصلی موبایل و دسکتاپ بدون نیاز به اپ‌استور.

### 🏆 ۷. مدال‌های افتخار، دستاوردها و گیمیفیکیشن
- **بخش مدال‌های افتخار در پروفایل کاربر:** نمایش بصری نشان‌ها شامل «کرم کتاب»، «سحرخیز»، «استادِ استمرار»، «شکارچی ایده»، «مسافر آفلاین» و «دانشمند فرهیخته».
- **محاسبه خودکار و پویا:** ارزیابی آنی وضعیت قفل یا باز بودن مدال‌ها با توجه به زنجیره روزانه، دقایق مطالعه، کتاب‌های خوانده‌شده، هایلایت‌ها و دانلودهای آفلاین.
- **سیستم پاداش XP:** افزایش امتیاز تجربه و نمایش درصد پیشرفت کلی کاربر به همراه فیلتر «همه»، «کسب‌شده» و «در انتظار».
- **اهداف مطالعه روزانه (Daily Goals):** تایمر فعال مطالعه، چالش ماهانه و ردیاب زنجیره استمرار (Streak).

### 🎨 ۸. طراحی استاندارد و ارگونومیک (Eye-Friendly Design)
- رعایت اصول کنتراست استاندارد WCAG برای محافظت از چشم در جلسات مطالعه طولانی.
- انیمیشن‌های روان و سیال با `motion`.
- کامپوننت‌های بهینه‌سازی شده بدون المان‌های بصری شلوغ و خسته‌کننده.

### 🛡️ ۹. پنل ادمین و مدیریت محتوا
- امکان افزودن، ویرایش و حذف کتاب‌ها.
- مدیریت بنرهای تبلیغاتی، رتبه‌بندی‌ها و تنظیمات سامانه.

## 🚀 نصب و راه‌اندازی محلی (Local Setup)

برای اجرای پروژه روی سیستم شخصی خود مراحل زیر را دنبال کنید:

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/your-username/kholaseh-kadeh.git

# ۲. ورود به دایرکتوری پروژه
cd kholaseh-kadeh

# ۳. نصب پکیج‌ها و وابستگی‌ها
npm install

# ۴. اجرای سرور توسعه
npm run dev
```

پروژه به صورت پیش‌فرض روی آدرس زیر در دسترس خواهد بود:
```
http://localhost:3000
```

برای تهیه نسخه نهایی پروداکشن:
```bash
npm run build
```

## 💡 پیشنهادها و نقشه راه آینده (Roadmap)

توسعه‌های جذاب بعدی که می‌توانند این پلتفرم را به یک اکوسیستم بی‌رقیب تبدیل کنند:

1. 🎙️ **پخش‌کننده صوتی خلاصه کتاب‌ها (Audio Summaries & AI TTS):**
   - تولید نسخه صوتی با صدای طبیعی هوش مصنوعی فارسی برای گوش دادن در حین رانندگی، ورزش یا پیاده‌روی با امکان تنظیم سرعت پخش.
2. 🗂️ **کارت‌های نقل‌قول گرافیکی (Shareable Quote Cards):**
   - امکان تبدیل هایلایت‌ها و جملات طلایی هر کتاب به تصاویر مربعی آماده برای استوری اینستاگرام و کانال‌های تلگرام با یک کلیک.
3. 🧠 **کوییز و آزمون کوتاه ۳ سوالی پایان هر کتاب:**
   - تست‌های تستی چندگزینه‌ای برای سنجش ماندگاری نکات در ذهن و اهدای سکه یا امتیاز گیمیفیکیشن.
4. 📱 **خروجی اپلیکیشن اندروید (APK via Capacitor):**
   - بسته‌بندی پروژه PWA در قالب فایل APK و انتشار آسان در کافه‌بازار و مایکت.
5. 🤖 **دستیار هوشمند پرسش و پاسخ درباره کتاب (Book AI Q&A):**
   - امکان چت کردن با هوش مصنوعی مستقر بر متن کتاب برای پاسخ به سوالات عمیق‌تر خواننده پیرامون ایده‌های نویسنده.
